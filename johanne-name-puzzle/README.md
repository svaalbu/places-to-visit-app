# JOHANNE, with 5×2 mm magnets

The board is turned 45° on a Bambu Lab P2S. Each letter has two magnet pockets, and the board has the matching pocket under each one. The letters are printed face-down, so the shiny bed surface is the face that shows on top of the puzzle. In the slicer they look upside down; turned shiny-side up, they read the right way.

| | |
| --- | --- |
| Board | 295.0 × 63.9 × 10.5 mm |
| On the bed, after the turn | 247.5 mm across, about 4.2 mm clear of each edge |
| Letters | Scaled to 68% of the FINN size. J and E are small enough to drop through the printer's small-parts opening. |
| Magnets | 2 in every letter, and the same 14 pockets in the board floor |
| Pocket | 5.4 mm across, 2.2 mm deep, for a 5×2 mm disc |
| Plate 1, Board | Pause at 3.20 mm |
| Plate 2, Letters 1 | J, O, H, A. Pause at 10.80 mm |
| Plate 3, Letters 2 | N, N, E. Pause at 10.80 mm |

Print the board slots up and the letters face-down. PLA, 0.20 mm layers. On the board, use 9 top shells and 9 bottom shells so the floor stays solid. Ironing off. Brim off. Leave the layer height at 0.20 mm so each pause lands on the open pocket.

When the printer pauses, drop the magnets in. Put every letter magnet in the same way up, and flip the board magnets over, so each pair pulls together.

The file is `johanne_name_puzzle.3mf`.
