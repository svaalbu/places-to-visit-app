# JOHANNE, with 5×2 mm magnets

The board is turned 45° on a Bambu Lab P2S. Each letter has two magnet pockets near the bed, and the board has the matching pocket under each one. The letters print with the show face up, and that top face is ironed. In the slicer they read the same way as in the finished puzzle.

| | |
| --- | --- |
| Board | 295.0 × 63.9 × 10.5 mm |
| On the bed, after the turn | 247.5 mm across, about 4.2 mm clear of each edge |
| Letters | Scaled to 68% of the FINN size. J and E are small enough to drop through the printer's small-parts opening. |
| Magnets | 2 in every letter, and the same 14 pockets in the board floor |
| Pocket | 5.4 mm across, 2.2 mm deep, for a 5×2 mm disc |
| Plate 1, Board | Prints by layer. Pause at 3.20 mm |
| Plate 2, Letters 1 | J, O, H, A. Prints by layer. Pause at 2.80 mm |
| Plate 3, Letters 2 | N, N, E. Prints by layer. Pause at 2.80 mm |

The file already sets 0.20 mm layers, 5 top shells, 5 bottom shells, 0.1 mm elephant foot compensation, and no brim. The show face is monotonic lines, then ironed on the topmost surface: rectilinear lines, 10% flow, 0.1 mm spacing, 15 mm/s, and a 0.2 mm inset. Five shells close the covers, and the middle of the floor stays infill. Print the board slots up and the letters show-face up, in PLA.

Every plate is set to print by layer, so the pause is available. The letter marker is at 2.80 mm. The printer stops before that layer, while the pocket is still open.

Stack the magnets so they hold together in a column. The face that is on top of every disc in that stack goes up, in the letters and in the board. The letter's underside then meets the board's top face, and those are opposite poles, so the letter pulls into the slot.

The file is `johanne_name_puzzle.3mf`.
