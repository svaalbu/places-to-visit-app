# Name puzzles

Wooden-style name puzzles for a Bambu Lab P2S. Each letter drops into a slot of its own shape.

- [FINN](finn-name-puzzle/README.md) is one board.
- [VICTOR](victor-name-puzzle/README.md) is the same letter size in one row. The board is two pieces that key together, because the full row is longer than the 256 mm bed.
